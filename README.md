# e-plantShopping

## Paradise Nursery

e-plantShopping is a React and Redux-based houseplant shopping application. The application allows users to browse a variety of houseplants, add plants to a shopping cart, adjust quantities, remove items, and view the total cost of their purchases.

## Features

- Landing page for Paradise Nursery
- Browse houseplants by category
- Minimum six plants per category
- Add plants to the shopping cart
- Dynamic shopping cart item count
- Increase and decrease plant quantities
- Remove plants from the cart
- Calculate individual item totals
- Calculate the overall cart total
- Continue shopping navigation
- Checkout button with a "Coming Soon" message

## Technologies

- React
- Redux Toolkit
- React Router
- JavaScript
- CSS
- Vite
